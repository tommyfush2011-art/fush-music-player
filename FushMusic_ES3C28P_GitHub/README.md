# FushMusic ES3C28P
Upload the contents of this archive to the root of a GitHub repository, including the hidden .github directory. If GitHub's upload interface skips it, create .github/workflows/build.yml manually and copy the included workflow text. Open Actions and run Build FushMusic ES3C28P. Download its artifact if successful. The application binary is firmware.bin; use only a compatible launcher installation method. This project assumes 16 MB flash and octal PSRAM; verify your actual hardware and launcher partition compatibility first. Source unchanged from supplied main.cpp. Build and hardware operation have not been tested. ESP8266Audio is pinned to an older version for Arduino ESP32 2.x compatibility.
